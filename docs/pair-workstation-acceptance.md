## 审查中发现并修复

1. 混合新旧报价可能误触发永久回撤停机：陈旧估值不更新高水位/日基准/熔断，并禁止新增仓位；界面回撤显示不可用。
2. 离线超过三天或界面截断最近 100 笔可能漏补资金费：从完整持久化账本生成待核对清单，两腿都在平仓 72 小时后成功核对才结束主动补记。72 小时是当前公开结算延迟容忍假设；事后超过该窗口的交易所历史修订不自动持续重查。
3. 一个币种异常零报价影响其他组：公共报价逐币验证，失效组保留，其他新鲜报价继续可用。
4. Windows 解压临时目录导致账户数据位置变化：打包入口将账户放在稳定输出目录；文件锁防止不同端口并行写同一账户。

## 适用范围

该验收证明功能和核算链路，不证明策略盈利。尚未执行新组合模型的历史回测、样本外检验或长时间模拟盘收益验证。统计筛选存在多重检验/过拟合风险；模拟成交未建模撮合队列、部分成交、最小订单规则和逐仓强平。旧单组回测与旧实盘桌面应用独立保留，不能把其结果当作新模型的验证。

日志在 `outputs/pair_workstation/paper.sqlite3`，页面日志栏可导出 CSV。界面验收合成账户位于独立系统临时目录，未写入正式模拟账本。
